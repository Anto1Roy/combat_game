# Combat Game MVP Architecture

This repository documents a PC-first Unreal Engine 5 melee combat prototype. The focus is on physics-driven combat, split-screen local multiplayer, and a networking-ready architecture. The content here outlines systems, controls, and folder structure to accelerate implementation inside an actual UE5 project.

See `docs/` for detailed design guidance and `Source/` for C++ stubs illustrating key gameplay components.

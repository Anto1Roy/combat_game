# Source Layout

C++ stubs illustrating the gameplay architecture. These headers are Unreal-style and meant to guide in-engine implementation.

- `CombatGame/Actions/` — data structures and helpers for combat actions.
- `CombatGame/Components/` — reusable gameplay components (state, stamina, action execution).
- `CombatGame/Characters/` — character class wiring movement, input, and components.
- `CombatGame/Weapons/` — weapon hitbox management and collision sweeps.

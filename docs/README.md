# Documentation Index

This folder contains high-level guidance for the PC-only Unreal Engine 5 melee combat prototype. Each subfolder dives into a specific area with actionable steps for engineering and design teams.

- `architecture/` — overall project structure, gameplay layers, and replication considerations.
- `combat/` — combat loop, action data, and hit detection strategy.
- `multiplayer/` — split-screen setup and networking-ready patterns.
- `animation/` — parametric animation guidance and placeholder usage.
- `testing/` — recommended in-editor test flows and debug HUD tips.
